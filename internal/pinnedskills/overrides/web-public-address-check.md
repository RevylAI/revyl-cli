- Check an address yourself before you register it. `curl -sSL -o /dev/null -w '%{http_code}' <address>` must print `200`, and the `<title>` in the page that `curl -sSL <address>` returns must match what the code renders, such as the `<title>` in `index.html` or the root layout's metadata. A bot check, a parked domain, a hosting placeholder, a different product, or an empty title fails the check. If the page that `curl -sSL <address>` returns says `Blocked request. This host` or `Invalid Host header`, the dev server refuses the tunnel's host name: restart it for this run with the tunnel's host allowed, such as `__VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS=<tunnel host>` before Vite's dev command, without editing the app's config files, and check again. Any other `403` means access is denied: leave the dev server alone, and the address fails the check.
